# OrderIt 🍔🛒

OrderIt is a modern food ordering and management platform developed to simplify the online ordering experience for customers and restaurant owners. The application provides an interactive user interface, seamless ordering workflow, secure authentication, and efficient order management.

---

## 🚀 Features

### 👤 User Features

* User Registration & Login Authentication
* Browse Food Items and Categories
* Search and Filter Products
* Add to Cart Functionality
* Secure Checkout Process
* Order Placement & Tracking
* Responsive and User-Friendly Interface
* Mobile-Friendly Design

### 🛠️ Admin Features

* Admin Dashboard
* Add / Update / Delete Products
* Manage Orders
* Manage Users
* Track Sales and Orders
* Inventory & Menu Management

---

## 🏗️ Tech Stack

### Frontend

* React.js
* Tailwind CSS / CSS

* React Router DOM

### Backend

* Node.js

### Database

* MongoDB

### Other Tools & Technologies

* JWT Authentication
* Git & GitHub

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/VijayFencer/OrderIt.git
```

### 2️⃣ Navigate to the Project Directory

```bash
cd OrderIt
```

### 3️⃣ Install Dependencies

#### Install Frontend Dependencies

```bash
cd client
npm install
```

#### Install Backend Dependencies

```bash
cd ../server
npm install
```

---

## 🔑 Environment Variables

Create a `.env` file in the server directory and add the following:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

---

## ▶️ Running the Application

### Start Backend Server

```bash
cd server
npm start
```

### Start Frontend

```bash
cd client
npm start
```
